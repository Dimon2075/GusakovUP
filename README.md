## 📌 Описание выполненной работы
В рамках индивидуального задания учебной практики разработан полнофункциональный MVP-модуль (микросервис ядра) для автоматизации контроля ИТ-задач. Приложение спроектировано на базе архитектурного паттерна **MVVM** для платформы **WPF (.NET Framework)** и интегрировано с базой данных **Microsoft SQL Server**.

В соответствии с командным распределением, под личный контроль взято ядро из **3 связанных таблиц** базы данных (`Users`, `Projects`, `Tasks`). Реализован сквозной бизнес-цикл: от регистрации сотрудников со строгим шифрованием данных до построения аналитических срезов и интерактивного CRUD-управления.

## 🛡️ Реализованные подсистемы информационной безопасности
1. **Криптографическая защита учетных записей:** Исключено хранение паролей в открытом виде. Реализован алгоритм **PBKDF2 (SHA-256)** с генерацией уникальной криптографической соли, преобразующий пароль в массив `byte[]` для хранения в СУБД в поле типа `varbinary(64)`.
2. **Защита от брутфорс-атак:** Интегрирован счетчик неверных попыток авторизации. После **3 неудачных вводов** форма блокируется и активируется подсистема генерации растровой графической капчи (динамический рендеринг случайных символов и линий помех средствами `DrawingVisual`), исключающая автоматический перебор.
3. **Безопасное удаление данных:** Реализован механизм мягкого каскадного удаления записей (**Soft Delete**) на базе флага `IsDeleted`. Все критические действия пользователя (удаление задач, выход из профиля) защищены модальными окнами подтверждения операций.

## 💻 Функциональные возможности интерфейса (UX/UI)
* **Разграничение ролей:** Интерфейс динамически адаптируется под роль вошедшего (`Administrator` получает полную панель CRUD и аналитики, `User` — только просмотр и поиск своего контента).
* **Поиск и фильтрация:** Полноценная обработка коллекции `ICollectionView` средствами LINQ. Мгновенный поиск по символам, фильтрация по связанным проектам и статусам задач происходят «на лету» без избыточных запросов к СУБД.
* **Экспорт отчетов:** Разработан сервис выгрузки отфильтрованных данных в форматы документов **MS Excel (.xlsx)** через EPPlus, **MS Word (.docx)** через DocX и кроссплатформенный **PDF (.pdf)** через iTextSharp.
* **Блок визуальной аналитики:** Программный расчет и математическое построение круговой диаграммы соотношения задач по статусам средствами векторной геометрии WPF (`Canvas`, `ArcSegment`).
* **Брендбук и кастомизация:** Оформление полностью соответствует корпоративному руководству по стилю (шрифт Open Sans, фиксированные сетки элементов). Реализовано переключение Светлой и Темной тем с сохранением выбора в `App.config`.

## 🗂️ Структура репозитория
* **`/GusakovUP/`** — Исходный код программного комплекса:
  * `/Models/` — Контекст данных (`UpEntities`) и сгенерированные классы ADO.NET Entity Data Model (`Model1.edmx`).
  * `/ViewModels/` — Классы бизнес-логики окон и обработки команд (`MainViewModel`, `LoginViewModel`, `ChartViewModel`).
  * `/Views/` — Визуальная разметка XAML и код-биханд окон системы (`LoginWindow`, `RegisterWindow`, `MainWindow`, `AddTaskWindow`, `EditTaskWindow`, `ChartWindow`).
  * `/Services/` — Сервисные модули хэширования, капчи, конвертеров и генерации отчетов.
  * `/Styles/` — Словари динамических ресурсов тем оформления (`LightTheme.xaml`, `DarkTheme.xaml`, `ColorsAndFonts.xaml`).
